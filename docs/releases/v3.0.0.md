# v3.0.0

This release identifies the database changes since v2.0.0: seven new tables, ETF and sovereign gold bond labels in
`consolidated.ins_type`, a schema number in the file, and the removal of Yahoo responses for tickers no longer in
`consolidated`.

## Breaking database changes

- **`ins_type` labels ETFs and SGBs** ([#52](https://github.com/rehanhaider/stocky/pull/52)). Exchange-traded funds,
  whose ISIN starts with `INF`, are now `etf` rather than `equity`, and sovereign gold bonds are `sgb`. A query that
  filters `ins_type = 'equity'` no longer returns ETFs. This database has 4,510 `equity`, 367 `etf`, and 43 `sgb` rows.
- **Schema number** ([#67](https://github.com/rehanhaider/stocky/issues/67)). The file records its layout in
  `PRAGMA user_version`, which reads `1` for this release; files written before it read `0`. `stocky status` and
  `stocky summary` show it.
- **Orphaned Yahoo responses removed** ([#83](https://github.com/rehanhaider/stocky/pull/83)). `yahoo_responses` no
  longer keeps responses for tickers that are in neither `yq_ns` nor `yq_bo`: 1,358 were removed, and the file
  shrank from 49.0 MB to 40.9 MB.

```sql
SELECT isin, nse_symbol, yq_ns
FROM consolidated
WHERE ins_type = 'etf';
```
