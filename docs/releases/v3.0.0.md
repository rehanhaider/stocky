# v3.0.0

This release identifies the database changes since v2.0.0: seven new tables, ETF and sovereign gold bond labels in
`consolidated.ins_type`, a schema number in the file, and the removal of Yahoo responses for tickers no longer in
`consolidated`.

## Breaking database changes

- **`ins_type` labels ETFs and SGBs** ([#52](https://github.com/rehanhaider/stocky/pull/52)). Exchange-traded funds,
  whose ISIN starts with `INF`, are now `etf` rather than `equity`, and sovereign gold bonds are `sgb`. A query that
  filters `ins_type = 'equity'` no longer returns ETFs. This database has 4,510 `equity`, 367 `etf`, and 43 `sgb` rows.
- **Schema number** ([#67](https://github.com/rehanhaider/stocky/issues/67)). The file records its layout in
  `PRAGMA user_version`, which reads `1` for this release; files written before it read `0`. `stocky status` and
  `stocky summary` show it.
- **Orphaned Yahoo responses removed** ([#83](https://github.com/rehanhaider/stocky/pull/83)). `yahoo_responses` no
  longer keeps responses for tickers that are in neither `yq_ns` nor `yq_bo`: 1,358 were removed. The file is
  40.9 MB, against 39.6 MB at v2.0.0 and 49.0 MB for the last build before this release, which held those responses
  and the new tables.

```sql
SELECT isin, nse_symbol, yq_ns
FROM consolidated
WHERE ins_type = 'etf';
```

## Included database

The versioned database is `data/output/stocky.db` in the repository at tag `v3.0.0`.
It is not attached as a separate release asset.

- SHA-256: `d173305ca9763cc2a6719e4f87b2d15cd4a8714f61a9edd305a4609b1813972e`.

Compared with the database at `v2.0.0`:

| | v2.0.0 | v3.0.0 |
| --- | --- | --- |
| Bhavcopy trade date | 2026-07-17 | 2026-09-30 |
| `consolidated` rows | 4,707, `INF` ETFs labelled `equity` | 4,920: 4,510 `equity`, 367 `etf`, 43 `sgb` |
| `yahoo_responses` rows | 8,338 | 7,513 |
| Tables | 2 | 9 |
| File size | 39.6 MB | 40.9 MB |

The data was built with `stocky refresh --date 2026-09-30 --stale-days 90`:

- The BSE and NSE bhavcopies are the 2026-09-30 files of the last build before this release (identical SHA-256). The
  Zerodha instruments, mutual fund, AMFI, and broker files were downloaded **2026-11-27** (IST); against that build,
  158 `consolidated` rows changed, all in Zerodha symbols, and none were added or removed.
- 7,511 of the `yahoo_responses` rows were fetched on 2026-10-21. The refresh fetched only 77 tickers: 75 with no
  response and 2 with one over 90 days old. Yahoo answered one of the two (`DALMIASUG.NS`, now dated 2026-11-26);
  `CONCORD.BO` still holds its 2026-05-31 response, and the 75 still have none.
- `stocky summary` passes every check; see [`data/output/refresh-summary.md`](../../data/output/refresh-summary.md).

Raw source files remain local inputs and are excluded from Git.

The package metadata and `stocky version` both report `3.0.0`.
